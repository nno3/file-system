# File system

A small terminal that keeps folders and files in memory. You can list them, move around, create them, delete them, and rename them.

I wrote it in C++. This page runs the same commands in the browser.

Live page: https://nno3.github.io/file-system/

Commands: `cd`, `ls`, `pwd`, `tree`, `touch`, `mkdir`, `rm`, `rmdir`, `mv`, `load`, and `exit`. `load 1`, `load 2`, and `load 3` fill in the sample trees. The C++ source is in `cpp/`.
